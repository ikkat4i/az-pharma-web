# Favicon definitivo

Esta versión incluye:

- `app/favicon.ico` con varios tamaños;
- `public/favicon.ico` como respaldo para `/favicon.ico`;
- `app/icon.png`;
- `app/apple-icon.png`;
- `public/icon-192.png`;
- `public/icon-512.png`;
- `app/manifest.webmanifest`;
- metadata completa en `app/layout.tsx`;
- enlaces con versión `?v=3` para evitar caché antigua.

Después de publicar:
1. Esperar a que Vercel marque `Ready`.
2. Abrir la web en una ventana de incógnito.
3. Si Chrome conserva el ícono anterior, cerrar todas las pestañas de la web y volver a abrir.
